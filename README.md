# ESM-dev-server

Making a rip off of the Vite dev server for learning purposes.


### Goals

* Demystifying Javascript quirks that the bundlers usually hide from us
    * ESM vs CJS
    * Serving node_modules
    * Tree-shaking
    * Importing CSS files from JS files `import ./global.css`
    * This list will go on as I get deeper
* Learning with the ASSISTANCE of AI. Every keystroke will be done by my own fingertips, that is the line I've drawn just for this project.
* Minimal dependencies - in general see how Vite does it and ask if I feel like implementing the functionality. Even if it is much slower, much more insecure, or plain stinks :) 
* Would be cool to condense this into a single .ts file capable of running on modern Node. Currently running on v25.9.0 


There is a balance between faithfully following the Vite way of doing things vs. doing what I feel like.
